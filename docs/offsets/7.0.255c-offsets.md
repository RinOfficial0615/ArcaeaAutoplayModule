# Arcaea 7.0.255c offset evidence

Language: English | [简体中文](7.0.255c-offsets_CN.md)

Target: `libcocos2dcpp.so` (ARM64, stripped)

- SHA-256: `72e42cb4925655ecfef98bf2dbf92a5ac05145eb005a531c96c11b927a46e6dc`
- Build ID: `c8434354f4ad8f78481f592cc0c215202a58a056`
- FMOD provider SHA-256: `3803aad5303e8816573bb110ea69f5022df7291b7d0e7c509d5f2ce73e3927d3`

18 of the 19 consumed functions were relocated from 7.0.1c with
`scripts/port_match.py` as unique masked-instruction consensus winners whose
function extents are byte-for-byte identical to 7.0.1c; they are pinned in
`scripts/port_match_70255c_spec.json`, and the pinned locate pass and semantic
diff both completed. `ShowJudgementEffectAtNote` was rewritten in 7.0.255c
(0x598 -> 0xAC8 bytes, new prologue), so its pin is confirmed by exact masked
bytes at the pinned address instead. IDA 9 independently confirmed the version
global, direct call relationships, RTTI objects, asset-loader callsite,
registry global, and scenecontrol getter.

## Semantic confirmation

- The version setter at `0xF78E74` copies the Java string into the libc++
  string at `0x1BDFF80`; runtime detection therefore keeps its existing model.
- `processLogicNotes` reads the note vector at `Gameplay +0xA0/+0xA8`, walks
  it with the same Tap/Flick/Long/Arc/Camera/SceneControl dispatch as 7.0.1c,
  calls `ScoreState_applyMiss @ 0xE19784` and
  `ScoreState_applyJudgement @ 0xB4DB58`, and dynamic-casts through
  `_ZTI12LogicArcNote @ 0x1ACC9F0`. The miss-window timer reads keep the
  `+0x20/+0x28/+0x2D/+0x34` displacements of the shared Timer mirror.
- `tryTapJudgementForTouch` references both Hold and Arc RTTI objects
  (`0x1AAAB10` / `0x1ACC9F0`). ELF relative relocations bind the unique
  type-name strings `"13LogicHoldNote" @ 0x4BEE2B` / `"12LogicArcNote" @
  0x501E07` to those two `_ZTI` objects.
- `ShowJudgementEffectAtNote` was rewritten: its extent grew from `0x598` to
  `0xAC8` bytes and the frame layout changed. Identity is nevertheless
  established by the identical `img/hit_pure.png` / `img/hit_far.png` /
  `img/hit_lost.png` / `EARLY` / `LATE` string set and by both callers being
  `note_effect_on_miss +0x11C` and `note_effect_on_judgement +0xB8`, the exact
  call sites 7.0.1c used.
- `HttpClient_processRequest` switches over the request type at
  `request+0x0C` (reached via `response+0x10`), reads the body range at
  `+0x28/+0x30`, calls the relocated curl wrapper at `0xD2F7D8` for
  GET/POST/PUT/DELETE (10036 = `CURLOPT_CUSTOMREQUEST`, 10015 =
  `CURLOPT_POSTFIELDS`), and stores the status/succeed results at
  `response+0x50` / `response+0x18`.
- The tiny registry getter (`sub_161CB34`) reads the global at `0x1BE7028`
  and derefs it `+120` then `+24` — the exact chain 7.0.1c's getter performed
  over `qword_1BAEB28`. This establishes the song-registry owner global used
  before `find_song_by_id`; the relocated `find_song_by_id` keeps its map
  lookup at `arg+24`.
- The scenecontrol getter is still the unique 8-byte
  `LDRB W0,[X0,#0x110]; RET` sequence in the whole binary. It sits at
  `0x17B0140`.
- The songlist asset-open function is the relocated cocos2d-x
  `FileUtilsAndroid` asset path (12/13 anchor windows match, `+0x200` callsite
  pattern `BL; MOV X20,X0; CBZ X0` identical); its body grew from `0x418` to
  `0x744` bytes with no change to the callsite offsets.
- The paired gameplay, play-launcher, chart-path, and availability bodies keep
  all consumed object displacements. 7.0.255c therefore reuses the 7.0.x
  derived note layout (`isVoid +0xA4`, `activeNow +0xD0`, runtime X/Y
  `+0xD4/+0xD8`, hold-head `+0xA8`) and the unchanged custom-chart Song family
  (`remote_pack +0x1C0`, difficulty table `+0x228`, lock `+0xF0`).
- `libfmodProvider.so` still exports
  `_ZN24AudioProviderFMODAndroid7loadBGMEPKci` at `0x3A4E0` with size `0x3A0`.

## Reproduce the checks

```bash
python scripts/port_match.py locate ../7.0.1c/libcocos2dcpp.so \
  ../7.0.255c/libcocos2dcpp.so scripts/port_match_70255c_spec.json
python scripts/port_match.py diff ../7.0.1c/libcocos2dcpp.so \
  ../7.0.255c/libcocos2dcpp.so scripts/port_match_70255c_spec.json
python tests/verify_profile.py 7.0.255c
python tests/run_host_tests.py
./build.ps1 --rebuild --rel
```

`tests/verify_profile.py` pins the exact binary SHA-256, all hook prologues,
the songlist callsite, both digest guards, the scenecontrol getter, and every
runtime patch word.
