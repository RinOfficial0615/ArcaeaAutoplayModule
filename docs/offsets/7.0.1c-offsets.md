- SHA-256: `426ce11edb840514acf0056d9ba48b597cf30f796298461b16c4e4e113e8742d`
- Build ID: `4d0bad75646cdd051bc82d526ffb4fa99c5f6b88`
- FMOD provider SHA-256: `5aab120c929861a931d53676fd1b52363b08e9f0e9fe8be46214557e21c71983`

Every consumed function was relocated from 7.0.0c with
`scripts/port_match.py`. All 19 targets were unique consensus winners and were
then pinned in `scripts/port_match_7001c_spec.json`; the pinned locate pass and
semantic diff both completed successfully. IDA 9.3 independently confirmed the
version global, direct call relationships, RTTI objects, asset-loader callsite,
registry global, and scenecontrol getter.

## Semantic confirmation

- The version setter at `0x14AE3D4` copies the Java string into the libc++
  string at `0x1BAA8C8`; runtime detection therefore keeps its existing model.
- `processLogicNotes` reads the note vector at `Gameplay +0xA0/+0xA8`, calls
  `ScoreState_applyJudgement @ 0x140CFF4` and
  `ScoreState_applyMiss @ 0x11306E0`, and references
  `_ZTI12LogicArcNote @ 0x1B0DAC8`.
- `tryTapJudgementForTouch` references both new Hold/Arc RTTI objects. ELF
  relative relocations bind their unique type-name strings to
  `0x1AA4C68`/`0x1B0DAC8`.
- `HttpClient_processRequest` switches over request type at `request+0x0C`,
  reads the body range at `+0x28/+0x30`, and calls the relocated curl wrapper
  at `0x1A09024` for GET/POST/PUT/DELETE.
- The small getter at `0x16D88D8` reads `qword_1BAEB28`; this establishes the
  song-registry owner global used before `find_song_by_id`.
- The scenecontrol getter is still the unique 8-byte
  `LDRB W0,[X0,#0x110]; RET` sequence. IDA reports ten callers, including two
  from `tryTapJudgementForTouch`, matching 7.0.0c.
- The paired gameplay, play-launcher, chart-path, and availability bodies keep
  all consumed object displacements. 7.0.1c therefore reuses the 7.0.x derived
  note layout (`isVoid +0xA4`, `activeNow +0xD0`, runtime X/Y
  `+0xD4/+0xD8`, hold-head `+0xA8`) and the unchanged custom-chart Song family
  (`remote_pack +0x1C0`, difficulty table `+0x228`, lock `+0xF0`).
- `libfmodProvider.so` still exports
  `_ZN24AudioProviderFMODAndroid7loadBGMEPKci` at `0x25FFC` with size `0x3A0`.

## Reproduce the checks

```bash
python scripts/port_match.py locate ../7.0.0c/libcocos2dcpp.so \
  ../7.0.1c/libcocos2dcpp.so scripts/port_match_7001c_spec.json
python scripts/port_match.py diff ../7.0.0c/libcocos2dcpp.so \
  ../7.0.1c/libcocos2dcpp.so scripts/port_match_7001c_spec.json
python tests/verify_profile.py 7.0.1c
python tests/run_host_tests.py
./build.ps1 --rebuild --rel
```

`tests/verify_profile.py` pins the exact binary SHA-256, all hook prologues,
the songlist callsite, both digest guards, the scenecontrol getter, and every
runtime patch word.
